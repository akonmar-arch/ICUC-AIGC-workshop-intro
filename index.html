课程信息一览

以国际传播任务为主线，将 AI 工具使用、跨文化表达和项目实践贯穿整个学期。通过个人练习与团队协作，把中国主题转化为面向海外受众的多语种、多模态内容。每次生成都回到受众与事实，每次修改都留下判断依据。

W1 / 课程内容

AI原理与实践

认识 LLM 大语言模型与 Agent 智能体，思考 AI 时代自己的学习、创作与行动方向。

学习目标

  • 理解什么是 LLM 大语言模型
  • 理解什么是 Agent 智能体及其与 LLM 的关系
  • 思考 AI 时代自己该怎么做，并形成个人心得

课堂内容

  1. 什么是LLM大语言模型
  2. 什么是Agent智能体
  3. AI时代，你该怎么做。

课堂实践

结合个人学习与创作场景，讨论 LLM 与 Agent 的应用方式，梳理 AI 时代自己的行动方向，并构思课程个人心得的表达形式。

课后作业

在个人电脑上安装 Workbuddy 和 Obsdian，然后用 Workbuddy 基于 W1 课程内容做一份课程个人心得。形式不限，可以是 DOCS、PPT、视频、图片、思维导图等。

W2 / 课程内容

Agent 入门：从对话到任务

理解智能体如何围绕目标使用工具、推进步骤，并在关键节点交回人工判断。

学习目标

  • 区分大模型对话、固定工作流与 Agent
  • 画出目标、步骤、工具、状态与反馈之间的关系
  • 设计一个有输入、输出和人工审核节点的入门任务

课堂内容

  1. 概念区分：大模型提供理解与生成能力；Agent 在目标与约束下组织行动；固定工作流按预设步骤执行。
  2. 基本结构：目标与角色、模型、工具、上下文或状态、反馈检查，以及停止条件。
  3. 任务拆解：把“做一条校园介绍”拆成材料整理、受众判断、文案生成与质量检查。
  4. 边界与责任：工具访问应按任务授权；发布、重要修改和事实判断保留人工确认。

课堂实践

小组设计“校园国际传播小助手”：输入校园事实材料与受众信息，输出介绍文案和核查清单。先画流程，再用可用平台配置原型或逐步模拟执行，记录一次失败和修正。

课后作业

暂不布置课后作业。

W3 / 课程内容

国产 AI 工具全景图

围绕文本、图像、视频、音频与工作流任务建立工具选择方法。

学习目标

  • 建立任务与工具的对应关系
  • 用统一材料比较工具输出
  • 说明选择依据与使用限制

课堂内容

  1. 工具地图：按生成模态与任务组织工具，而不是只记产品名称。
  2. 对照方法：同一输入、同一输出标准，对比准确性、表达、可控性与操作成本。
  3. 组合使用：先批量构思，再精修、核查与人工定稿。

课堂实践

用两款可用工具处理同一段跨文化介绍，记录各自优点、错误和修改成本，整理个人工具清单。

本周交付

工具比较表 + 个人能力地图

W4 / 课程内容

实验周 1：多语种自我介绍

把个人经历转化为面向不同语言受众的 30 秒短片。

课堂内容

  1. 中文基线：先写真实的个人经历与记忆点。
  2. 多语种表达：中文、英文与一种小语种的表达适配及核查。
  3. 成片检查：声音、字幕、画面一致；添加 AI 使用说明与必要标识。

课堂实践

生成与试听多语种口播，制作数字人或人物介绍短片，开展同伴观看反馈并修改。

30 秒多语种短片 + AI 使用声明

W5 / 课程内容

AI 辅助选题

从受众兴趣与信息需求出发，找到中国主题的传播切口。

学习目标

  • 区分主题、选题和叙事角度
  • 从材料中提出可核实的选题
  • 给出选题筛选理由

课堂内容

  1. 选题来源：公开材料、生活观察与受众提问。
  2. AI 发散：从同一主题生成不同受众、形式与角度的候选方案。
  3. 人工筛选：以相关性、事实支撑、制作可行性筛选。

课堂实践

围绕一个中国主题生成候选选题，选择三个并写出受众、核心问题、素材来源和否决理由。

本周交付

3 个海外可传播选题 + 筛选依据

W6 / 课程内容

跨文化写作

让信息在不同文化语境中被理解，而不是只完成字面翻译。

学习目标

  • 识别受众已有知识与理解障碍
  • 调整叙事开头和解释方式
  • 保留事实的一致性

课堂内容

  1. 受众与语境：补足必要背景，避免把刻板印象当作受众画像。
  2. 表达改写：将抽象口号转化为具体人物、行动和细节。
  3. 双语校对：核查专名、数字、引文与语气。

课堂实践

将一篇中文介绍改写为面向目标海外受众的版本，对照开头、背景解释和表达方式，标注修改理由。

本周交付

600 字中文稿及英文适配稿 + 改写说明

W7 / 课程内容

AI 视觉与视频

把文字脚本转化为分镜与声音，完成短片生产的第一轮闭环。

学习目标

  • 从脚本拆出可制作镜头
  • 比较视觉与视频工具的表现
  • 保持人物、画面和声音一致

课堂内容

  1. 分镜设计：镜头目的、景别、时长、画面描述和声音。
  2. 生成控制：用参考素材与清晰约束提高风格和角色一致性。
  3. 剪辑整合：检验节奏、字幕、配音和素材来源。

课堂实践

用同一镜头描述进行工具对照，并将选定镜头、配音与字幕组装成一条短片初版。

W9 / 课程内容

课堂内容

W10 / 课程内容

多版本分发策略

课堂实践

W12 / 课程内容

实验周 3：授权投放与数据记录

W14 / 课程内容

投放数据复盘

用数据回答传播是否有效，并明确证据能够支持到什么程度。

学习目标

课堂实践

选择一个传播表现变化，回看对应片段与评论，提出解释假设和下一轮验证方法；模拟数据须明确标注。

AI International Communication Practice is a 16-week project-based undergraduate course. Students learn about large language models and agents, create multilingual content, build workflows, and evaluate communication through evidence. Attendance accounts for 40% of the final grade, and coursework accounts for 60%.
